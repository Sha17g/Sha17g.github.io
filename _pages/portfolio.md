## Computer Science

### Open-Source Development on `rgbds-live`
Extended [rgbds-live](https://github.com/gbdev/rgbds-live), a WebAssembly-powered browser IDE for Game Boy (SM83) assembly programming that integrates the RGBDS compiler toolchain and the Binjgb emulator (Supervised by Prof. Guillaume Hoffmann, Spring 2026).
  * **Editor & Workflow Enhancements**: Improved the customized Ace Editor integration and project management workflow by implementing configurable SM83 code autocompletion, persistent font-size scaling, and batch file importing, with all features merged into the official upstream repository.
  * **Multi-Context Architecture Refactoring**: Reorganized the single-instance front-end architecture into a modular, class-based design to decouple project storage, compilation pipelines, and emulator states, enabling tab-based workspace switching and parallel execution of multiple assembly targets.
